# sooyo 品牌规范

sooyo 是一个可组合、本地优先的个人空间，也是与个人 Agent 协作的日常入口。品牌表达：**温和、聪明、有条理**。

推荐短句：**让信息有序，让日常从容。**

## 名称与图形

- 品牌字标固定为小写 **sooyo**；产品界面名称继续使用 **sooyo daily**。技术标识 `dsh-sooyo`、API 与已有领域术语保持原样。
- 鸟形以用户提供的品牌展示图为设计依据，灵感源于良渚玉鸟；这是现代品牌演绎，不作为文物图样复原或机构关联声明。
- 鸟眼表达关注与理解；左翼四格对应可组合的 Widget；右翼信息条对应整理信息；头顶三道橙色光芒表达灵感和回应。
- 正式标识为平面矢量重绘，保留展示图的主要轮廓与构成。展示图中的纸纹、光影和手绘起伏不作为 Logo 的必要部分。字标是重新绘制的圆润路径字形，并非原图的精确字体复刻。

## 品牌色

以下色值是依据展示图制定的平面标准色，不是对含纹理图片每个像素的机械取样。

| 名称 | HEX | 角色 |
| --- | --- | --- |
| Navy · 深靛蓝 | `#282D55` | 字标、应用图标背景、深色品牌版面 |
| Cobalt · 钴蓝 | `#344DA8` | 彩色鸟形主体 |
| Terracotta · 陶土橙 | `#DF793D` | 光芒与少量品牌强调 |
| Clay · 陶土浅棕 | `#E9B68C` | 鸟形内部模块及腹部 |
| Stone · 暖石色 | `#F1D5BC` | 反色鸟形、浅色辅助面 |
| Off-white · 暖白 | `#FFF6EC` | 品牌展示背景、反白字标 |

品牌色不自动等于 UI 状态色。正文、链接、危险操作、成功提示继续使用产品的语义色；这次只接入品牌标识，不重做整个界面主题。不要用陶土橙承载暖白底上的小号正文。

## 尺寸、留白与背景

- 主标建议宽度不小于 **160 px**；独立完整版鸟形建议宽度不小于 **48 px**。
- 16–32 px 优先用 `symbol-small.svg`。它是光学简化版，不要将完整主标硬缩到导航图标尺寸。
- 应用图标建议不小于 **32 px**；顶部 26 px 属于紧凑界面的实际应用，鸟形身份优先于内部装饰细节。
- 图形实际外缘周围至少留出鸟形宽度的 **1/8**；组合主标上下与四周同样保留这份距离。SVG 画布不是完整安全区，排版时需要另加留白。
- 彩色主标用于暖白或接近白色的干净背景；深色背景使用反白版。应用图标保留自身的深靛蓝底。
- 单色标使用一种实色，孔隙保持透明；不要给镂空部分涂上与背景无关的白色。
- 保持长宽比，不旋转、不拉伸，不单独移动眼睛、光芒或双翼，不追加阴影、渐变、外描边或纹理。宣传插画可以使用材质，但不要覆盖正式标识。

## 产品接入与维护

- 插件安装图标：根目录 `icon.svg`，仍由 `package.json` 的既有 `icon` 字段引用。
- 顶部品牌入口：`client.js` 内嵌应用图标，旁边保留可访问的 `sooyo daily` 文本。
- DSH 侧栏：内嵌小尺寸单色标，继承 `currentColor`，适配宿主深浅主题；可访问名称仍由侧栏按钮提供。
- 说明文档：中英文 README 使用横向主标，并链接本规范。
- 源文件是 [dev/generate-brand.mjs](../dev/generate-brand.mjs)。修改路径或配色后执行 `node dev/generate-brand.mjs`，同步 SVG、预览页、根图标及 Client 中带标记的内嵌图形；随后重新导出 PNG。
- PNG 可在浏览器中按目标宽度将 SVG 绘制到透明 Canvas 后导出，保持原始 `viewBox` 比例。不要将旧 PNG 放大充当新版素材。
- 这些文件随既有 `assets` 打包。品牌 SVG 不经过仅服务 Widget WebP 的 `/sooyo/assets/` 路由；Client 使用可信内嵌图形，没有新增资源请求或 Host 路由。
